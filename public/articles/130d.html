02 / 核心卖点

按购买决策重要度排序

排序依据是消费者决策权重，而非素材出现顺序：先回答“有没有效果”，再回答“干不干净”（130D 的存在理由），然后“麻不麻烦”，最后才是体验功能。

顺序卖点与证据消费者价值
01 加湿效率与大空间覆盖400ml/h 额定加湿量（检测报告 JD202300376）、聚拢大出雾口高位出雾、三档雾量、适用 30-50㎡。 先解决“客厅大、加湿慢、只湿机器周围”的第一顾虑。400ml/h + 大水箱是它区别于桌面小机型的硬指标。
02 三重水路净化（130D 的立身之本）麦饭石过滤水质 + UV-C 光解除菌（除菌率报告 JD202300375）+ 活水循环系统（吸水式结构不间断循环，缩短水体停留时间）。 回应超声波加湿器最敏感的“水箱久放滋生细菌、雾气是否干净”问题，也是相比 130C 多花几十元的核心理由。
03 负离子空气净化（金色版专属）金色 / 金色 WiFi 款搭载负离子发生器，官方素材表述为“分解异味细菌、沉降颗粒物”。 从“水干净”延伸到“空气清爽”，是卧室与易敏人群的加分项。注意它是加湿器的辅助净化，不能当空气净化器宣传。
04 13L 大水箱与长续航按 400ml/h 理论计算满水约 32.5 小时；素材场景为“白天加满水，晚上持续加湿”。 一天半才加一次水，减少频繁补水，适合持续开空调、暖气的家庭；大口径水箱也方便伸手清洗。
05 智能变频恒湿高精度湿度感应器实时监测，40%-70%RH 可调，大屏数显当前湿度。 避免一直喷雾造成过湿返潮，卧室、老人房和育儿家庭更省心；湿度数显让“效果”看得见。
06 加水与操控不弯腰顶部揭盖上加水、大口径；上置触控大屏 + 红外遥控；WiFi 款支持 APP 远程。 13L 落地机最怕“加水累、操作弯腰”，上加水 + 上置屏 + 遥控把日常使用成本降到最低。
07 睡眠体验与安全结构≤38dB 低噪、睡眠模式熄屏无光；上抽水式结构（上置主机 + 下置水箱），官方强调“无漏水隐患”。 满足夜间卧室使用；防漏结构回应“加湿器泡坏地板”的隐性顾虑。表述应为“低噪运行”，不能称“无声”。
08 窄占地与低功耗180×180×765mm、净重 2.6kg、额定功率 25W。 18cm 见方占地贴墙可放；25W 连续开 24 小时理论耗电约 0.6 度，整季使用无电费压力。
03 / 产品文案

产品昵称与文案体系

命名参照竞品“加湿小方块”的“形状 + 气质”逻辑：130D 是 76.5cm 高的圆柱塔，顶部 UV-C 光解除菌——“灯塔”既说形态，也暗合“光解净化”。

推荐产品昵称 亚都净雾灯塔 SC400-YXS130D
三重净护，一塔润全屋

13L 昼夜长润｜UV-C + 活水 + 麦饭石三重水路净化｜40-70% 智能恒湿

三重净润 水先过滤，再光照除菌，雾气出发前三道关 麦饭石过滤水质、UV-C 光解除菌、活水循环不积水；金色版再加负离子净化空气。
巨雾速润 聚拢大出雾口，一小时 400 毫升水润向全屋 400ml/h 额定加湿量（报告 JD202300376），适用 30-50㎡ 客厅。
昼夜长润 白天加满一箱水，润到第二天晚上 13L 充沛容量，按 400ml/h 理论续航约 32.5 小时。
智感恒润 湿度有数，润而不过 40%-70%RH 可调，感应器实时监测，大屏数显当前湿度。
静夜轻润 润着，也睡着 运行噪声 ≤38dB，睡眠模式熄屏无光，整夜不打扰。
建议减少使用：“呼吸 0 风险”“母婴级柔雾”“健康黑科技”。“0 风险”属绝对化承诺，“母婴级”缺少标准依据；净化类表述应限定在“水路除菌 + 负离子辅助净化”，不可延伸为整屋空气净化或防过敏功效。
04 / 销售建议

人群 × 渠道 × 打法

推荐定位：“130C 的净化加强版——看重水雾卫生的家庭，多花几十元买三重净化”。销售主线是与 130C 做配置差，而不是与 180、130E 比大小。

人群与话术侧重

母婴/易敏家庭讲“水路三重净化 + 除菌报告”；客厅大空间用户讲“400ml/h + 13L”；上班族推金色 WiFi 款讲“下班路上 APP 开机，到家即润”。

渠道分工

天猫（青桔/梦驰）主推白色走量、承接搜索“除菌加湿器”；京东旗舰店同步白色 ¥329 价格锚点；金色 WiFi 款放在详情页顶部做版本升级引导，抬高客单。

与 130C 的同页对比

详情页放一张 130C / 130D 配置对照卡：同 13L、同 400ml/h，差异只在净化配置。让消费者为“净化”付费，而不是在两个链接间犹豫流失。

促销节奏

9-10 月开季以白色 ¥329 守价引流；双 11 主推金色款“负离子升级版”做满减；冬季暖气季推 WiFi 款“远程预约加湿”场景；避免白色与 130C 同时大幅降价互相打架。

连带销售

连带柠檬酸除垢剂 / 水箱清洗剂（超声波机型硬耗材），并主动提示硬水地区建议纯净水；确认麦饭石滤芯是否可单独复购，可则挂“配件”SKU 做老客复购。

口径与合规

除菌率必须绑定报告编号 JD202300375 与测试条件；32.5h 标注“理论值”；定时范围统一 1-12h 或 1-14h（当前矩阵与金色素材不一致）；噪音统一 ≤38dB 口径，金色素材的 37.8dBA 需确认是否为同工况实测值。
