02 / 核心卖点

按购买决策重要度排序

排序依据是购买影响力，而不是素材中出现的先后顺序。先回答“有没有效果、雾干不干净、用起来麻不麻烦”，再补充体验功能。

顺序卖点与证据消费者价值
01 双核大雾量，一台顶两台700ml/h 最大加湿量，双雾化芯高频雾化；详情页称“双核雾化芯，双倍雾量，一台顶两台”（商品主图7.jpg）。 先解决“加湿慢、开了跟没开一样”的核心顾虑。别墅、大平层、大客厅用户买的是覆盖能力，双核是最直观的效率证据。
02 水路三段净化体系麦饭石滤芯初滤 → 抽至顶部水槽 UV-C 照射杀菌 → 活水循环再雾化（商品主图4.jpg / 主图9.jpg）。 回应超声波加湿器最敏感的“水箱久放、雾气是否干净”问题。20L 存水更多，水路卫生比普通机型更必须讲清楚。
03 20L 超大水箱与上加水20L 海量储水，最大档理论续航约 28 小时；便捷上加水，可直加自来水（商品主图2.jpg）。 大面积场景最怕“半天一箱水”。一次补水覆盖全天，且不用搬机弯腰，直接从顶部加水。
04 防漏专利与可移动性主机提起防漏实用新型专利 ZL202022130660.5，上置主机 + 下置水箱、抽水结构不漏水；万向脚轮满水可移动（商品主图5.jpg / 主图1.jpg）。 大水箱机型特有的两个顾虑——“搬动会不会漏水”“满水挪不动”——用专利号和脚轮直接化解，这是 180 区别于杂牌大容量机的信任状。
05 高位远送出雾系统741mm 高挑机身 + 360° 旋转出雾口 + 标配加长导雾管，高强力风动装置提高出雾高度（商品主图1.jpg / 主图3.jpg）。 雾送得高、散得开，避免“只湿机器周围、打湿地板”。大面积均匀加湿的关键证据。
06 智能变频恒湿湿度数显 + 智能变频恒湿，自动调节输出（商品主图2.jpg，矩阵标注 ✅）。 避免大雾量机型一直喷雾造成过湿返潮，设定后不用人管，适合长时间开着的家庭与商铺。
07 轻音睡眠与安全保护矩阵口径“柔声”，详情页称 LIN 降噪轻音不扰；睡眠模式、缺水断电保护、1–14h 定时。 满足卧室与夜间商铺使用，降低缺水干烧风险。注意：无具体分贝值，表述限“低噪/柔声”，不可称“静音无声”。
08 低功率与水质宽容额定功率 55W；可直加自来水；EMC 国际检测合格（GB 4343.1-2018、GB17625.1-2012）。 全天开机电费压力小（55W 连续 24 小时理论约 1.32 度电），自来水可用降低使用门槛。

04 / 销售建议

人群 × 渠道 × 节奏

推荐定位：“适合别墅、大平层与大面积客厅的双核大雾量除菌加湿器”，卡位 090P / 130 系列（¥259–499）之上的高端走量款。

人群一：别墅 / 大平层家庭

核心话术“小机器带不动大空间”。用 700ml/h 双核 + 741mm 高位出雾对比普通桌面款，强调一台覆盖全屋，省得每个房间放一台。

人群二：暖气 / 空调房重度用户

主打 20L 长续航 + 智能恒湿：“全天开着不加水、不返潮”。北方供暖季重点投放，强调整夜、全天连续使用场景。

人群三：母婴与用水卫生敏感家庭

讲水路三段净化路径（麦饭石→UV-C→活水循环），配合防漏专利与缺水断电，落点是“水干净、机安全”，不做医疗化承诺。

人群四：商用保湿场景

官方主图已覆盖花卉店、果蔬超市、火锅店、风幕柜（商品主图6.jpg）。面向小微商户做团购与企业采购，话术“食材花草保鲜，一台管一店”。

渠道侧重：天猫 + 直播

天猫主图锚定 ¥580–599 价格带，用“一台顶两台”建立性价比；直播演示双核雾量对比、提起主机不漏水、万向轮满水推行三个可视化动作。

促销节奏

9–10 月蓄水（收藏加购 + 预约），双 11 / 双 12 主推“别墅级大雾量”并赠加长导雾管；1 月深冬做“暖气房干燥”场景返场。沿用主图“价保 30 天、买贵退差”承诺降低决策门槛。

连带销售

麦饭石滤芯（耗材复购）、加长导雾管（配件 / 赠品）、除垢剂与纯净水建议（硬水地区）；向卧室场景连带 050 / 090P 小容量款，“客厅 180 + 卧室 090P”组合销售。

口径红线

噪音只说“柔声 / 低噪”（无分贝标称值）；续航标注“理论值”；潜水泵 / 抽水泵随机发货需提前告知；18L 版价格与参数上架前需单独确认。
